# FocusVeil

FocusVeil 是一个原生 macOS 菜单栏应用。它会识别当前活动窗口，保持该窗口原有显示，并压暗其他窗口和背景区域。当前窗口不会被边框、光晕或额外留白强调。

## 功能

- 自动跟随当前活动窗口
- 支持同一应用内的窗口切换
- 支持多个显示器和全屏空间
- 支持调节背景压暗强度
- 支持登录时启动
- 不截取屏幕，也不保存窗口内容

## 系统要求

- macOS 13 或更高版本
- Xcode Command Line Tools
- 辅助功能权限

辅助功能权限只用于读取当前活动窗口的位置和尺寸。FocusVeil 不读取窗口中的文字、图像或文件。

## 构建

在仓库根目录运行：

```bash
zsh Scripts/build.sh
```

构建完成后，应用压缩包会生成到：

```text
outputs/FocusVeil.zip
```

解压后可以得到应用包。

## 使用

1. 解压构建得到的应用压缩包。
2. 打开 FocusVeil。
3. 在菜单栏中打开 FocusVeil 菜单，选择打开辅助功能设置，并在系统设置中为 FocusVeil 启用辅助功能权限。
4. 回到日常使用的窗口后，FocusVeil 会保持当前活动窗口原有亮度，并压暗其他窗口和背景区域。
5. 在菜单栏中打开 FocusVeil 菜单，可调整背景压暗强度或设置登录时启动。

如果系统设置没有直接定位到辅助功能页面，可以手动进入隐私与安全性，然后在辅助功能中为 FocusVeil 打开权限。

## 实现说明

应用使用 macOS 辅助功能接口识别当前活动窗口，并结合系统窗口列表取得对应窗口编号。全屏透明面板绘制压暗层，然后被放在当前活动窗口下方，使活动窗口保持原有亮度，其他窗口和背景区域被压暗。绘制逻辑不添加边框，也不在窗口周围保留额外透明区域。

构建脚本会调用系统 clang 编译单个 Objective C 源文件，然后使用本地临时签名生成应用包。该签名适合个人使用和开发验证。若要面向其他用户分发，需要使用 Apple Developer 证书完成正式签名和公证。
