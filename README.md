# FocusVeil

FocusVeil 是一个使用 AppKit 编写的原生 macOS 菜单栏应用。它自动识别当前活动窗口，并使用不拦截鼠标操作的透明遮罩压暗其他区域。

## 功能

- 自动跟随活动窗口
- 支持同一应用内的窗口切换
- 可选择突出当前窗口或当前应用的全部窗口
- 支持多个显示器和全屏空间
- 可调节背景压暗强度
- 可设置遮罩颜色、过渡时间和窗口留白
- 提供通用、外观、显示器与高级设置页面
- 可暂停五分钟
- 可设置登录时启动
- 不截取或保存屏幕内容

## 系统要求

- macOS 13 或更高版本
- 辅助功能权限

## 构建

安装 Xcode Command Line Tools 后，在项目目录运行：

```bash
chmod +x Scripts/build-app.sh
./Scripts/build-app.sh
```

构建完成后，应用压缩包位于 `outputs/FocusVeil.zip`。解压后即可得到 `FocusVeil.app`。

## 使用

1. 解压 `FocusVeil.zip`，将 `FocusVeil.app` 移入应用程序文件夹。
2. 打开 `FocusVeil.app`，程序会自动显示设置窗口。
3. 在通用页面打开系统辅助功能设置，并允许 FocusVeil。
4. 根据需要调整外观、显示器和高级设置。
5. 关闭设置窗口后，遮罩会自动开始工作。需要再次设置时，点击菜单栏中的半圆图标。

## 实现说明

应用通过 macOS 辅助功能接口读取当前窗口的位置和尺寸。它不会读取窗口中的文字、图像或文件。全屏透明窗口负责绘制背景遮罩，并在活动窗口位置保留透明区域。
